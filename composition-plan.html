L6 · Composition Plan

Complete one row for every positioned, layered, clipped, rounded, or shape-wrapped element. Duplicate rows as needed.

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
.figure-badge Shows featured picture with a visual label. With no positioning, it would be placed in the normal flow. I chose absolute positioning to place the badge in a specific location relative to its container picture. I used var(--layer-raised) for the z-index. If absolute positioning fails, it will fall back to the normal flow but still be readable. Chrome testing confirmed the badge is visible and properly positioned without disrupting the layout.
.feature-figure Holds and displays the featured image, caption, and badge. It would remain in normal flow, but has no specific positioning. Relative positioning was used to allow for holding the figure in normal flow while giving positioning reference for its badge. No layer token, only relative positioning. If removed, normal flow would continue but the badge would not be positioned as intended. Verify the image remains in normal flow while the badge is properly positioned in the corner.
.story-guide Provides a guide for navigating the story. Without sticky positioning, it would remain in normal flow, but has no specific positioning and will scroll away with the page. Sticky positioning was used to keep the guide visible while scrolling. No layer token, sticky positioning creates a new stacking context. If removed, the guide would scroll away with the page. Scroll the page and verify the guide remains visible.
.shape-portrait Creates a portrait-shaped container for the image without the surrounding text interfering. It would remain in normal flow, but no circular wrapping would be applied and the text falls below the image. float: inline-start was used to place the image at the left of its container. While shape-outside allowed the text to wrap around the image. No layer token needed, shape-outside creates a new stacking context through controlling wrapping.. Without shape-outside, the text would not wrap around the image. Disable shape-outside and verify the text is readable and falls below the image.
.feature-figure img Creates a featured image container without changing the layout. Without clip-path, the image would have a rectangular shape. Clip-path creates a polygon shape but doesn't take up any additional space. Clip-path creates a new stacking context without z-index. If removed, the image stays in its rectangular shape, and text is still readable. Add the disabling token to the clip-path property, verified the rectangular shape took form.
